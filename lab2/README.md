# Лабораторна робота №2
**Тема:** Розробка консольних утиліт для задач кібербезпеки  
**Варіант:** 2 (Детектор цілісності файлів та каталогів - FIM)

## Структура проєкту
- `task1.py` - реалізація системи моделювання користувачів, безпечних сесій та логування (ООП).
- `task2.py` - консольна утиліта для моніторингу несанкціонованих змін у критичних директоріях (FIM).
- `main.py` - головна точка входу для запуску завдань.
- `data/` - директорія з тестовими даними (розпаковано з архіву `lab2_data.zip`, варіант `data_v02`).

## Вхідні файли
Утиліта FIM приймає на вхід будь-яку директорію для моніторингу. Для тестування використовується папка `data/monitored/`, яка містить файли конфігурацій та скрипти (наприклад, `config/app.conf`, `scripts/backup.sh` тощо).

## Встановлення залежностей
Для роботи скриптів необхідно встановити залежності з кореня репозиторію:
```bash
pip install -r requirements.txt
Приклади запуску
Завдання 1 (Демонстрація ООП моделі користувачів):

Bash
python -m lab2.main demo
Завдання 2 (Режим генерації еталону - generate):

Bash
python -m lab2.main analyze --dir lab2/data/monitored --baseline lab2/data/baseline.json --mode generate
Завдання 2 (Режим перевірки цілісності - check):

Bash
python -m lab2.main analyze --dir lab2/data/monitored --baseline lab2/data/baseline.json --mode check
Аргументи CLI (Завдання 2)
--dir (обов'язковий): Шлях до директорії, яку потрібно сканувати та моніторити.

--baseline (обов'язковий): Шлях до JSON-файлу, де зберігається (або буде збережений) еталонний стан файлів.

--mode (обов'язковий): Режим роботи програми. Може бути generate (створення еталону) або check (перевірка поточного стану з еталоном).

--log-file (необов'язковий): Шлях до файлу журналу аудиту (за замовчуванням fim_audit.log).

Поведінка при помилках
Якщо вказана директорія (--dir) не існує, програма виведе повідомлення: Помилка: Директорія <шлях> не існує.

Якщо в режимі check не знайдено еталонний файл (--baseline), програма повідомить: Помилка: Еталонний файл не знайдено.

При спробі ввести неправильний формат email для користувача в Завданні 1, буде викликано виняток ValueError: Некоректний формат email.
